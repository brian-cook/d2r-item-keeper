# D2R Items to Keep — Season 14 / Patch 3.2 (Reign of the Warlock)

> **Current as of:** May 2026 — Season 14 start (May 22, 2026), Patch 3.2  
> **Expansion:** Reign of the Warlock (Patch 3.0+), featuring the Warlock class, Grimoires, ~30 new items, new runewords Void / Ritual / Coven / Blood Boil / Apocalypse, reworked Sunder Charms, and stackable stash tabs.  
> **Critical Patch 3.2 note:** The bug fix that caused Echoing Strike to drain ethereal weapon durability was **reverted**. Ethereal weapons are once again fully safe for player characters on Warlock builds and all others.

## SECTION 1 — BASES

**Legend:**
- **ETH** = Ethereal only (merc use or no-repair advantage)
- **NORM** = Non-ethereal (player-equipped runeword)
- **BOTH** = Either version has value
- **SUP** = Superior is preferred (adds up to 15% Enhanced Damage/Defense)
- Sockets listed in order of preference (best → acceptable)

## SECTION 2 — RARES

**Guide:** Only the slots and max values that genuinely matter in the current meta are listed. Sub-optimal slots are skipped. An item is worth keeping if it hits at least the bolded core stats.

---

| Stat | Max Roll |
|---|---|
| +2 to Class Skills | Fixed max for class skills |
| Faster Cast Rate | 10% (max on rare amulets) |
| Life | 40 (amulet max) |
| Mana | 40 |
| Strength / Dexterity | 10–15 each |
| All Resistances | 10 |

| Life Replenish | 3–8 |

**Keep if:** +2 to a class (Paladin / Sorceress / Necromancer / Druid / Barbarian / Amazon / Warlock) **+ 10% FCR + any two useful secondary stats** (life, mana, str/dex, resist). FCR on an amulet is extremely rare and sends value soaring. Without FCR, look for class skills + high life + a resist.

### RARE CIRCLETS / CORONETS / TIARAS / DIADEMS — Max Values

These are among the most valuable rare items in D2R; their unique ability to roll class skills + FCR + stats + sockets is unmatched.

| Stat | Max Roll |
|---|---|

| Faster Run/Walk | 30% |

| Mana | 70 |
| All Resistances | 10 |
| Single Resistance | 35–40 |

**Keep if:** +2 class skills **+ 20% FCR** (core combo, extremely valuable). Bonus points for life (40+), mana (40+), str/dex (10+), sockets (1–2), or resist. Even a +2 / 20% FCR circlet with modest secondaries is high value.

**By class priorities:**
- Paladin: +2 Pala / 20% FCR / life / dex

- Druid: +2 Druid / 20% FCR / str / life
- Barbarian: +2 Barb / 20% FCR / str / life
- Amazon: +2 Ama / 20% FCR / dex / life

## SECTION 3 — MAGIC ITEMS

Magic items to keep are primarily those that serve as crafting inputs, are best-in-slot for specific builds, or can hit rolls that rare/unique items cannot.

---

### MAGIC AMULETS — Keep If

**For crafting:** Any magic amulet of any level serves as a crafting input for caster/blood/safety amulets. Keep ilvl 90+ magic amulets from Hell Act 4–5 areas for maximum affix pools.

**To keep as-is:**
- +2 to a class skill tree + 10% FCR (can be gambled; rare drop)
- +3 to a specific skill tree (used for crafting if ilvl correct)

Max magic amulet rolls:
- +2 Class Skills / +3 Skill Tree
- 10% FCR
- 20% single resist (varies)
- Life / Mana (moderate ranges)

---

### MAGIC GLOVES — Keep If

Magic gloves are often best-in-slot or crafting inputs for specific builds.

| Target | Reason |
|---|---|
| **3% LL + 20% IAS** | BiS Barbarian melee switch gloves ("3/20 gloves"); can only appear on magic gloves |
| **+3 Javelin Skills + 20% IAS** | BiS Javazon magic gloves |
| **+3 Bow Skills + 20% IAS** | Bowazon alt |
| **30% IAS** (max on magic only) | Some builds spec for this |
| **3% LL + 20% IAS + 30% FBR** | Smiter / hybrid Paladin BiS crafting template |

Max magic gloves are often **better than rare gloves** for specific builds. IAS cap on magic gloves is 30% (rare max is 20%).

---

### MAGIC BOOTS — Keep If

| Target | Reason |
|---|---|
| **40% FRW + 10% FHR + any resist** | Endgame crafting base or direct use |
| **30% FRW + tri-res (small amounts)** | Usable for many builds |

Magic boots serve primarily as crafting inputs. The Cube recipe for blood/safety boots needs a magic boot base. Higher FRW on the base carries over to the craft.

---

### MAGIC CIRCLETS / CORONETS / TIARAS / DIADEMS — Keep If

Magic circlets are primarily obtained through gambling; found drops from Hell monsters are also valuable.

| Target | Reason |
|---|---|
| **+3 to a Skill Tree (any class)** | BiS for specific builds (e.g., +3 Fire Skills Sorc, +3 Warcries Barb); can be upgraded via crafting with new Worldstone Shard recipes |
| **+2 Class Skills + 20% FCR** | Strong player headgear if stats line up |
| **+2 Warlock Skills + 20% FCR** | Very high demand in Season 14 |
| **1–2 Sockets + +2 Class Skills** | Socket via Larzuk for powerful base |

Tiaras and Diadems are the preferred gambling targets because they have the lowest STR requirement while still allowing 3-socket outcomes.

---

### MAGIC SHIELDS — Keep If

Magic shields **cannot be used for runewords**. White (normal/superior/ethereal) bases are required for Spirit, Exile, Phoenix, and all other runewords. Magic shields have value only as direct-use gear or crafting inputs.

| Target | Reason |
|---|---|
| **Magic Monarch with 40% All Resistances (Prismatic prefix)** | Best possible magic shield for a non-Paladin caster while farming a white 4-socket Monarch for Spirit. 40% all res is the max via the Prismatic prefix. |
| **Magic Paladin Shield with 40% All Resistances + 2 sockets** | Usable budget Paladin shield while farming a white 4-socket Sacred Targe or Vortex Shield. Sockets allow jewel enhancement. |

Note: Once you have a white 4-socket base and the runes for Spirit, the magic shield is obsolete. These are transitional, not endgame.

## QUICK-DECISION CHECKLIST

**ALWAYS keep:**
- Any ETH 4/5/6-socket elite weapon (polearm, sword, maul, axe)
- Any non-ETH Monarch (keep, Larzuk for 4 sockets if needed)
- Any Archon Plate / Mage Plate / Dusk Shroud with 3 or 4 sockets
- Any Grimoire with 2+ sockets
- Any magic or rare Circlet with +2 class skills + 20% FCR
- Any rare Gloves with +2 skill tree + 20% IAS
- Any rare Boots with 30% FRW + 2+ resistances (20%+)
- Any rare Amulet with +2 class skills + 10% FCR
- Any rare Ring with 10% FCR + leech/stats

**Usually keep:**
- Superior (10%+ ED) white armor/weapon bases in elite tier
- ETH elite armor bases with 4 sockets (all types)
- Magic Druid Pelts / Barb Helms / Necro Shrunken Heads with +3 to a skill tree
- Daggers (any) with +3 to a Warlock skill

**Examine and consider:**
- Rare Grimoires with any +3 to Warlock skills
- Rare Belts with FHR + STR + secondary of 2+ stats
- Rare Rings without FCR but with double leech + str (melee chars)
